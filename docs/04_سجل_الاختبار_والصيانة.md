## قائمة فحص قبل التشغيل

- [ ] لا توجد أسلاك مكشوفة أو نقاط قصر.
- [ ] جميع مداخل ESP32 لا تتجاوز 3.3V.
- [ ] مقاومات مقسم الجهد موصلة لكل حساس.
- [ ] الأرضي مشترك بين الوحدات.
- [ ] البطارية سليمة ومحمية ودائرة تنظيم الجهد مناسبة.
- [ ] الشاشة ووحدة MPU6050 موصلتان على I2C بشكل صحيح.
- [ ] بطاقة الذاكرة تحتوي ملفات MP3 الصحيحة.
- [ ] تم إجراء المعايرة قبل التدريب.
- [ ] تم اختبار القفاز على الطاولة قبل ارتدائه.

## صيانة دورية

- افحص الأسلاك المرنة عند الأصابع قبل كل جلسة.
- افحص تثبيت الحساسات ولا تسمح بثنيها بعنف.
- راجع حرارة المنظم والبطارية ووحدة الصوت.
- أعد المعايرة إذا تغير تثبيت الحساس أو القفاز.
- احتفظ بنسخة احتياطية من الكود وبيانات التدريب عند إضافة آلية تصدير مستقبلية.
