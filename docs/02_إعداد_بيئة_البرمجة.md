# إعداد بيئة البرمجة

## البرنامج المطلوب

- Arduino IDE 2.x على Windows أو Linux أو macOS.
- حزمة لوحات ESP32 من Espressif عبر Boards Manager.
- كابل USB يدعم نقل البيانات وليس الشحن فقط.

## المكتبات المطلوبة

ثبت المكتبات التالية من Library Manager:

1. Adafruit MPU6050
2. Adafruit Unified Sensor
3. Adafruit GFX Library
4. Adafruit SSD1306
5. DFRobotDFPlayerMini

مكتبة `Wire` و`Preferences` تأتيان مع حزمة ESP32 ولا تحتاجان عادة إلى تثبيت منفصل.

## إعداد اللوحة

- Board: ESP32 Dev Module أو الاسم المطابق للوحة المستخدمة.
- Upload Speed: ابدأ بـ 115200 أو قيمة مستقرة تدعمها اللوحة.
- Port: منفذ USB الصحيح.
- Serial Monitor: 115200 baud.

## ملاحظات توافق

الكود يستخدم واجهات Arduino-ESP32 مثل `analogReadResolution` و`analogSetPinAttenuation` و`Preferences`. إذا ظهرت أخطاء ترجمة، راجع إصدار حزمة ESP32 والمكتبات، ولا تغير تعريفات الأرجل عشوائيا.
