# جدول التوصيلات الكهربائية

## 1) حساسات الانحناء الخمسة

كل Flex Sensor يحتاج مقسم جهد مستقل. التوصيل المقترح لكل إصبع:

- طرف الحساس الأول إلى 3.3V.
- طرف الحساس الثاني إلى نقطة القياس.
- نقطة القياس إلى مدخل ADC المحدد وإلى مقاومة 10kΩ.
- الطرف الآخر للمقاومة إلى GND.

| الإصبع | مدخل ESP32 |
|---|---:|
| الإبهام | GPIO32 |
| السبابة | GPIO33 |
| الوسطى | GPIO34 |
| البنصر | GPIO35 |
| الخنصر | GPIO36 |

قد تختلف اتجاهات القراءة حسب نوع الحساس وطريقة المقسم. البرنامج يعاير وضع اليد المفتوحة والقبضة ليحسب نسبة الانحناء، لكن يجب التأكد من أن مدى كل حساس أكبر من الحد الأدنى المطلوب.

## 2) ناقل I2C المشترك

| الوحدة | طرف الوحدة | ESP32 |
|---|---|---|
| MPU6050 | SDA | GPIO21 |
| MPU6050 | SCL | GPIO22 |
| OLED SSD1306 | SDA | GPIO21 |
| OLED SSD1306 | SCL | GPIO22 |
| الوحدتان | GND | GND مشترك |
| الوحدتان | VCC | جهد التشغيل الصحيح حسب لوحة الوحدة |

الشاشة ووحدة MPU6050 تشتركان في خطي SDA وSCL. تأكد من عدم وجود تعارض في عنوان I2C؛ البرنامج يفترض عنوان شاشة 0x3C ويبدأ MPU6050 على 0x68.

## 3) DFPlayer Mini

| DFPlayer Mini | ESP32 / الطاقة |
|---|---|
| TX | GPIO16 (RX2 في ESP32) |
| RX | GPIO17 (TX2 في ESP32) عبر مقاومة تسلسلية قرابة 1kΩ كحماية/تخفيف مستوى |
| VCC | تغذية 5V مستقرة حسب مواصفات الوحدة |
| GND | GND مشترك |
| SPK1 وSPK2 | طرفا السماعة |

لا توصل السماعة إلى GPIO. لا تستخدم خرج مكبر الصوت مع مدخل Line منفصل.

## 4) الطاقة والبطارية

**مخطط آمن مبدئي:** بطارية Li-Po أحادية الخلية -> وحدة شحن TP4056 محمية -> مفتاح -> منظم/رافع جهد مناسب -> تغذية ESP32 والوحدات حسب جهدها وتيارها.

- TP4056 مخصص لشحن خلية ليثيوم واحدة؛ لا يرفع الجهد إلى 5V.
- لا توصل خرج البطارية 3.7V مباشرة إلى طرف 5V/VIN دون التأكد من مواصفات لوحة ESP32.
- لا توصل 5V إلى أي GPIO في ESP32.
- يجب أن يكون GND مشتركا بين ESP32 وMPU6050 وOLED وDFPlayer ودائرة الحساسات.
- افحص القطبية والجهد بالملتيميتر قبل تركيب البطارية.
- لا تشحن البطارية وهي مثبتة على اليد، ولا تستخدم بطارية منتفخة أو تالفة.
